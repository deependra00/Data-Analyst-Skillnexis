# Power BI Dashboard Guide

## Import
Open Power BI Desktop and import `PowerBI_Data.xlsx`.

## Suggested dashboard
### KPI cards
- Record Count
- Average Calories
- Average Duration
- Average Pulse
- Average Maxpulse

### Charts
1. **Duration vs Calories** — scatter chart; X = Duration, Y = Calories.
2. **Calories over Date** — line chart; X = Date, Y = Calories.
3. **Pulse vs Calories** — scatter chart; X = Pulse, Y = Calories.
4. **Workout table** — Date, Duration, Pulse, Maxpulse, Calories.

### Slicers
- Date
- Duration
- Pulse

## Important
The dataset does not contain Sales/Revenue, so do not label the dashboard as a Sales dashboard unless a Sales field is added. For the current dataset, use a title such as `Workout & Calorie Analytics`.
